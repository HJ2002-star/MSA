## [Boot4] 변경
- `resilience4j-spring-boot3:2.3.0` -> `resilience4j-spring-boot4:2.4.0` (+ `resilience4j-reactor`, `resilience4j-bom` 2.4.0). boot3 모듈은 Boot 3용
- 교재가 추가한 `spring-boot-starter-aop`는 12장에서 이미 `spring-boot-starter-aspectj`로 넣어서 생략
- `ProductCompositeIntegration`의 Jackson 3 import(`tools.jackson`)는 유지하고 resilience4j import만 추가
- `test-em-all.bash`: `circuitbreakerevents`의 `stateTransition`이 `CLOSED_TO_OPEN` 대신 `State transition from CLOSED to OPEN` 문장으로 나와 기대값 3곳 수정 (전이 순서는 동일)

## 복습 포인트
- 어노테이션 순서: `@Retry` -> `@TimeLimiter` -> `@CircuitBreaker`. 안쪽이 서킷 브레이커라 타임아웃 실패가 서킷에 집계된다
- 서킷 열림(OPEN) 후에는 fallback(`getProductFallbackValue`)이 즉시 응답. productId 13은 fallback에서도 404
- 설정은 `config-repo/product-composite.yml`: 타임아웃 2s, 재시도 3회, 5회 중 50% 실패 시 OPEN, 10초 후 HALF_OPEN
- `delay`, `faultPercent` 파라미터로 지연·오류를 주입해 복원력을 시험한다 (product 서비스)
- 클라이언트 오류(InvalidInput, NotFound)는 `ignoreExceptions`라 서킷을 열지 않는다
- 알려진 불안정: review `getReviewsMissingParameter` 간헐 실패 (11장부터 재현, ch12 노트 참고)
- 결과: test-em-all(서킷 브레이커 포함) 통과
