# 11장 API 보안: HTTPS + OAuth2/JWT (쪽수 확인 필요)

## 명령
- 빌드: `cd ~/MSA/Chapter11 && ./gradlew build` (Docker 필요)
- 방식: 10장 사본 + 교재 10->11 diff 패치 적용 / 이미지 갱신: `docker compose build`
- 통합 검증: `./test-em-all.bash start stop` (https://localhost:8443, 토큰 발급·401·403·Swagger 포함)

## [Boot4] 변경
- 리소스 서버 의존성: 교재의 `spring-security-oauth2-resource-server`+`-jose` 대신 `spring-boot-starter-security-oauth2-resource-server` (gateway, composite). Boot 4는 JWT 디코더 자동 구성을 이 모듈로 분리해서, 교재 방식은 `ReactiveJwtDecoder` 빈이 없어 gateway 컨텍스트가 뜨지 않는다
- 인증 서버 스타터: `spring-boot-starter-oauth2-authorization-server` -> `spring-boot-starter-security-oauth2-authorization-server`
- Spring Security 7: `OAuth2AuthorizationServerConfigurer`/`OAuth2AuthorizationServerConfiguration`이 `spring-security-config`의 `org.springframework.security.config.annotation.web.{configurers.oauth2.server.authorization, configuration}`로 이동
- 인증 서버 테스트: `@AutoConfigureMockMvc` -> `org.springframework.boot.webmvc.test.autoconfigure`, `spring-boot-starter-webmvc-test` 추가
- 인증 서버 Dockerfile 이미지 `21-jre-noble`, build.gradle은 Boot 4.0.7 / Java 21 / Cloud 2025.1.2

## 복습 포인트
- 외부 진입점이 8080(http) -> 8443(https, `edge.p12`). 자체 서명 인증서라 curl에 `-k`
- 인증 서버(9999)가 JWT 발급, gateway와 composite는 리소스 서버로 서명 검증. 권한은 `SCOPE_product:read/write`
- reader 토큰: GET 200, DELETE 403 / 토큰 없음: 401
- Eureka는 Basic 인증(u/p), 각 서비스 `defaultZone`에 자격 증명 포함
- 결과: 전체 build 통과, RabbitMQ `test-em-all.bash start stop` 통과 (Kafka/파티션 compose는 패치만 적용, 미실행)
