## 명령

- 통합 검증: `./test-em-all.bash start stop` (RabbitMQ 기본)

## [Boot4] 변경
- Spring Cloud `2025.0.0` -> `2025.1.2` (Boot 4.0.7과 짝. 2025.0.x는 Boot 4.0.1+ 비호환)
- composite에 `spring-boot-starter-webclient` 추가: Boot 4는 WebClient 자동 구성을 webflux 스타터에서 분리
- Health API 패키지 `boot.actuate.health` -> `boot.health.contributor`
- `Event`는 final 필드라 Jackson 3에서 역직렬화 실패(eventType=null): core 3개 yml에 `spring.jackson.mapper.allow-final-fields-as-mutators: true`
- `IsSameEvent*` 테스트: Jackson 3 패키지, `JsonMapper.builder().build()`, `JacksonException`
- 모든 yml/테스트에 5~6장 Boot 4 수정(spring.mongodb, `.value()`, `@AutoConfigureWebTestClient`) 재적용

## 복습 포인트
- 생성/삭제가 REST 동기 호출 -> 이벤트 발행(비동기, 202)으로 바뀌고 조회만 WebClient로 남는다
- 단위 테스트는 `Consumer`를 직접 호출해 직렬화를 건너뛴다. 메시지 직렬화 문제는 test-em-all에서만 드러났다
- 결과: 테스트 51개 통과(composite 8, product 13, recommendation 15, review 15), RabbitMQ test-em-all 통과
- `COMPOSE_FILE=docker-compose-kafka.yml`(또는 `-partitions.yml`) `./test-em-all.bash start stop` 둘 다 통과
